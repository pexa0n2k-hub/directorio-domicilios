# Directorio Inteligente de Domicilios — V1.5

Novedades:
- Domicilios separados por colonia.
- Filtro rápido de colonias en chips horizontales.
- Cada colonia muestra su grupo y cantidad de domicilios.
- Contador de colonias.
- Al registrar o editar un domicilio se puede indicar la colonia.
- Conserva foto, GPS, Google Maps, direcciones asociadas, personas, teléfonos y notas.
- Gestos: derecha → editar; izquierda → eliminar.
- IndexedDB para datos y fotos.
- Los registros anteriores se conservan y pasan a "Sin colonia" si no tenían colonia.

Ejemplo:
📍 Américas 1
  - Domicilio A
  - Domicilio B

📍 Américas 2
  - Domicilio C

📍 Niños Héroes
  - Domicilio D
